# 星际航运经营游戏

一款以星际客运网络规划为核心的网页经营游戏。

当前阶段是概念验证：验证玩家是否会享受观察需求、设计航线、配置船只，并在竞争和事件中持续优化运输网络的过程。

## 当前实现

项目已经包含一个无界面的 TypeScript 日结算模拟器：

- 根据星港属性和理论旅行时间生成三类客运需求
- 将往返线和环线自动展开为可售服务航段
- 搜索最多两次换乘的候选行程
- 根据票价、时间、频率、换乘、舒适度、声誉和准点率分配客流
- 在多个市场之间分配共享航段运力
- 结算服务航段及公司的收入、成本和利润

### 本地运行

需要 Node.js 24 或兼容版本。

```bash
npm install
npm test
npm run demo
npm run demo:campaign
```

常用命令：

```bash
npm run check  # TypeScript 类型检查
npm run build  # 编译到 dist
npm test       # 编译并运行情景测试
npm run demo   # 运行三港口示例
npm run demo:campaign # 运行20星港、196日战役示例
```

模拟器的公共入口是 `src/index.ts`，完整日结算入口是 `simulateDay()`。

## 网页界面

网页端支持可复现的随机银河生成、星域形状、恒星系与星港数量、超空间网络走向与密度配置，并提供：

- 可拖动的银河地图；每个语义尺度都有内容边界，越界拖动带阻尼并在松手后回弹
- 使用同一个 SVG 画布连续呈现“银河 → 恒星系 → 行星/卫星”，不再切换或重建地图组件
- 普通滚轮缩放以鼠标所指的世界坐标为中心，使用 85ms 非线性缓动降低输入延迟
- 银河、恒星系与行星尺度使用互不重叠的合法缩放区间；跨过阈值后会锁定并完成与双击相同的居中深入动画，不会停在层级之间
- 航线、轨道、标签与细节会随缩放值逐渐显隐，但恒星、行星和卫星始终是同一批可视对象
- 银河与恒星系层共享同一份 1 至 3 颗恒星数据，并显示行星轨道、卫星、随机星环、殖民地与星港位置
- 每颗行星和卫星拥有可复现的公转周期、自转周期与初始相位；播放时间时沿轨道连续运行，暂停后停止，表面自转使用降速后的视觉时间
- 恒星系与行星层使用统一深空星野，并以程序化球面光照、地表纹理、云带、裂纹、陨石坑和大气边缘表现不同类型行星
- 天体本体使用单一 Three.js WebGPU 画布渲染；行星采用 TSL 程序化球面材质，气态与冰巨星使用独立的大气条带生成器，并自动回退到 WebGL 2 / SVG
- 恒星按 O–M 光谱型使用独立的 TSL 程序化光球材质，呈现对流颗粒、活动区、缓慢自转与外层辉光
- 行星类型、人口（M/B）、发展度与经济类型数据
- 固定在顶部的当日收入、成本、利润、客流与可用资金
- 固定在底部的暂停、倍速和单日推进控制
- 发展度驱动的跨星需求，以及热门市场的额外 AI 竞争航线

```bash
npm run dev       # 启动本地开发服务器
npm run build:web # 构建静态网页到 web-dist
```

为保证当前单线程模拟器在浏览器中可用，交互式生成器暂时限制为最多 60 个星港。后续迁移至 Web Worker 后可以进一步提高上限。

## 第一版范围

- 约 6 个恒星系统、20 个星港
- 亚光速、曲速、超空间三种航行方式
- 经济、商务、高端三类旅客
- 往返线与环线
- 自动班次、运力和换乘计算
- 票价、燃料、维护和港口成本
- 基地、AI 竞争对手和市场事件
