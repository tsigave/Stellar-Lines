# 随机银河生成规格 v0.1

## 配置项

- 随机种子：相同种子和配置必须生成完全相同的银河。
- 恒星系数量：网页原型允许 3 至 24 个。
- 星港总数：每个恒星系至少一个，单个系统最多六个，总数暂时不超过 60 个。
- 星域形状：旋臂星群、均匀星盘、多星团。
- 超空间拓扑：邻近蛛网、中央放射、环形走廊、混合网络。
- 航道密度：在保证全图连通后增加额外超空间边。

## 生成顺序

1. 根据星域形状生成恒星系二维位置。
2. 生成唯一名称、恒星光谱类型和系统枢纽星港。
3. 将指定数量的其他星港分配到各恒星系。
4. 根据拓扑生成基础超空间网络。
5. 使用密度参数添加额外超空间边。
6. 在没有超空间直连的邻近系统之间生成少量曲速机会。
7. 在系统内生成枢纽至其他星港的亚光速边。
8. 生成玩家和AI公司的初始示范航线。

每个恒星系还会生成：

- 1至3颗恒星及其光谱类型
- 4至9颗行星及轨道
- 岩质、海洋、沙漠、冰封、火山和气态巨行星
- 至少一颗已住人行星
- 地表港、轨道港与深空站的位置

网页银河地图使用可缩放、可拖动的相机。星空纹理覆盖整个允许拖动的区域；相机到达默认世界边界后停止，避免玩家把航运网络完全拖出可恢复范围。

所有基础超空间网络必须保持连通。航段距离必须处于初始船型的航程范围内。

## 当前限制

- 玩家可以选择拓扑与密度，但尚不能在地图上逐条绘制或删除超空间边。
- 星港属性采用随机分布，尚未加入系统级经济主题的相关生成。
- 模拟在浏览器主线程运行，因此大地图高速推进会受到性能限制。
