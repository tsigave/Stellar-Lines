# 概念验证场景：六星系

该场景用于验证客运需求、不同推进方式、公司定位、竞争和事件变化，不代表最终世界观。

## 内容规模

- 6 个恒星系统
- 20 个星港
- 6 种船型
- 5 家公司
- 10 条初始航线
- 5 个预设事件
- 推荐观察周期：196 游戏日

## 恒星系统

| 系统 | 主要定位 | 星港数 |
| --- | --- | ---: |
| Sol | 首都、商务、成熟旅游市场 | 4 |
| Alpha Centauri | 行政与工业中心 | 3 |
| Sirius | 商务与度假市场 | 3 |
| Vega | 旅游和工业混合市场 | 3 |
| Tau Ceti | 新兴殖民地与农业市场 | 3 |
| Epsilon Eridani | 偏远殖民、科研和采矿 | 4 |

星系内主要使用亚光速接驳。各系统枢纽由固定超空间走廊连接，少数高价值港口之间存在曲速直达边。

## 船型定位

| 船型 | 座位 | 推进方式 | 主要用途 |
| --- | ---: | --- | --- |
| Pioneer Regional | 64 | 亚光速、曲速 | 偏远地区和区域直达 |
| Arrow Express | 48 | 亚光速、曲速 | 高频商务直达 |
| Meridian Liner | 180 | 亚光速、超空间 | 中型走廊班轮 |
| Atlas Grand Liner | 360 | 亚光速、超空间 | 低成本高运量干线 |
| Celestial Yacht | 84 | 亚光速、曲速 | 高价豪华服务 |

## 初始公司

| 公司 | 风格 |
| --- | --- |
| player | 多种市场组成的初始玩家网络 |
| nova-budget | 低价、大船、高运量 |
| swift-business | 高频、高速商务直达 |
| orbital-regional | 星系内区域接驳 |
| celestial-lines | 高舒适度豪华旅游 |

初始舰队经过基本校准，使不同定位都能争取合理客流。它不是最终平衡结果；后续应允许玩家从较小网络开始自行购买船只和开设航线。

## 事件时间线

| 开始日 | 事件 | 主要影响 |
| ---: | --- | --- |
| 30 | Alpha 星际工业博览会 | 商务及高端需求上涨 |
| 60 | Sirius 燃料危机 | 当地燃料价格上涨 |
| 90 | Vega 超空间风暴 | 航行时间增加、需求下降 |
| 120 | Aurora 灯光节 | 旅游需求上涨 |
| 160 | Frontier 移民潮 | 经济和商务需求上涨 |

每个事件会提前公布。事件结束后，其影响在恢复期内平滑消退。
