# v0.5.1：燃料更新

状态：已完成（2026-08-06）

## 版本目标

让燃料价格形成可观察、可利用的经营周期。玩家可以在低价时期为基地储备燃料，并在高价时期优先消耗库存，降低短缺行情对航线利润的冲击。

## 价格机制

- 普通行情使用以 2 Cr 为中心的多周期均值回归曲线，并以双曲正切形成 1–3 Cr 软边界，避免触底或触顶平台；
- 正常样本在 2 Cr 上下大致均衡分布，不能长期偏在 2 Cr 以下；
- 每个星港独立出现约十日的稀有供给行情，使用连续钟形包络渐入和渐出；
- 供给过剩时价格为 0.5–0.75 Cr；
- 供应短缺时价格为 5–6 Cr；
- 燃料事件和稀有行情叠加后的最终价格限制在 0.5–6 Cr；
- 已预告燃料事件用四日平滑曲线逐渐增强，并在恢复期平滑消退；
- 固定种子、星港和日期始终生成相同价格。

## 基地燃料库

- 公司基地拥有一个固定 2,500 FU 的燃料库；
- 当前版本不模拟卖家库存，玩家可按当前报价无限买入；
- 燃料库记录库存量、容量和加权平均购入成本；
- 只有从公司基地始发的玩家航线可以使用该库存；
- 库存不足时，剩余燃料自动按出发港现价采购。

## 自动策略

玩家可以分别关闭或设置两项价格阈值：

1. 自动买入：基地报价不高于阈值时，在资金允许范围内买入直至燃料库满；
2. 库存优先：基地报价不低于阈值时，基地始发航线先消耗库存燃料。

库存采购属于资产转换，买入时减少现金；库存被航线使用时按加权平均成本进入航线燃料成本，不重复产生现金支出。

## 本版本不包含

- 玩家建设或扩容多个燃料库；
- 卖家库存、订单深度、采购交期和港外调运；
- 不同基地间调拨燃料；
- 逐班次票款和燃料结算。v0.5.1 继续保留现有日汇总结算，班次粒度与真实时刻系统一并后续处理。

## 验收标准

1. 长周期样本中超过 90% 的报价位于 1–3 Cr；
2. 固定种子下可以复现 0.5–0.75 Cr 和 5–6 Cr 的稀有行情；
3. 正常区间位于 2 Cr 以上的样本占比保持在 40%–60%，任意相邻两日变化小于 1.5 Cr；
4. 低价阈值触发时燃料库自动买满或买到现金上限；
5. 高价阈值触发时基地始发航线优先消耗库存；
6. 非基地始发航线不能使用基地库存；
7. v0.5 存档可迁移到带空燃料库的 v0.5.1 状态。
