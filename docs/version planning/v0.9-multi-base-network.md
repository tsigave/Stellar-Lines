# v0.9：多基地与网络扩张

## 版本目标

取消所有玩家航线只能从唯一初始基地出发的限制。玩家可以投资多个运营节点，让舰船、人员、维护和转机网络围绕不同基地组织，同时承担扩张成本与管理复杂度。

## 1. 基地层级

建议保留一个总部，并提供三种运营层级：

| 类型 | 主要能力 | 主要限制 |
|---|---|---|
| 总部基地 | 公司管理、完整调度、最高维护能力、所有采购交付 | 全公司只能有一个，迁移昂贵 |
| 区域基地 | 航线起点、驻扎舰船、常规维护、人员与备用船 | 建设和固定成本较高 |
| 前进基地 | 少量驻扎、补给、换班和轻维护 | 容量小，不能完成大修或接收大型订单 |

总部可以迁移，但需要长准备期、费用和运营中断；不能通过瞬时切换规避远程运营成本。

## 2. 基地资源

每个基地至少追踪：

- 驻扎与过夜舰船容量；
- 可支持的每日始发航班；
- 船员与地勤能力；
- 维护机位、维修等级和每日工时；
- 备用船池；
- 仓储与系列备件覆盖；
- D–³He 燃料补给、亚光速引擎和曲率/超空间驱动器系列保障能力；
- 转机处理能力和连接时间修正；
- 固定成本、工资和当地费用。

第一版人员继续按能力池聚合，不逐名模拟。船体、亚光速引擎和 FTL 驱动系列集中度共同决定基地工具、培训与备件成本；沿用 v0.7 的公司级标准化规则，不再叠加一套重复折扣。

## 3. 建设与升级

玩家从符合条件的星港选择基地：

- 星港等级决定可建基地层级上限；
- 起降容量、当地成本、需求、网络位置和竞争影响选址；
- 建设需要资金和时间，占用星港长期容量；
- 升级分为驻扎、调度、维护、人员、转机五条能力线；
- 关闭基地前必须处理驻扎舰船、人员、航线和未完成维护。

基地投资纳入现金流和折旧，不能只作为一次性解锁费用。

## 4. 多起飞点与航线归属

- 玩家可以从任一具备始发能力的基地建立航线；
- 航线指定主要运营基地，但可访问其他基地；
- 环线和贯通航线可以经过多个基地；
- 舰船轮转必须定期返回支持其系列和维护等级的基地；
- 新交付舰船默认在总部验收，协议可加价指定区域基地交付；
- 动态调船需要真实调机航班、分阶段时间、D–³He 燃料和星港时隙。

航线不经过任何公司基地时产生远程运营成本；离开支持基地越久，人员调度、故障恢复和备用船响应越差。

## 5. 舰船与人员调拨

调拨类型：

- 商业航班中的正常轮转；
- 不售票的调机飞行；
- 临时借调后自动返回；
- 永久变更驻扎基地。

调拨预览显示飞行时间、燃料、丢失班次、时隙和新基地容量。飞行中、维修中或缺乏航程的舰船不能直接调拨。

人员能力不足时：

- 可执行班次受限；
- 周转时间增加；
- 维护排队延长；
- 晚点与取消风险上升。

## 6. 基地与枢纽的关系

基地不必是转机枢纽，转机枢纽也不必是完整基地：

- 基地描述航司资源组织；
- 枢纽描述旅客连接网络；
- 一个星港可以同时承担二者，也可以只承担其一。

区域基地可投资连接设施，降低自家和联程伙伴的最短连接时间。纯转机点缺少基地支持时，误机恢复和备用船能力较弱。

## 7. UI 范围

- 新增基地管理页面和银河基地图层；
- 显示每个基地的容量、舰船、人员、维护、成本和航线；
- 建线时选择运营基地，不再强制使用总部；
- 舰船卡显示驻扎基地、下一次返回和远程运营天数；
- 基地建设/升级提供需求、时隙、竞争和回收期预测；
- 通知中心提示容量溢出、维护排队、人员不足和长期离基地运营。

## 8. 财务规则

基地成本包括：

- 建设和升级资本支出；
- 设施折旧；
- 每日租金、人员和管理固定费；
- 非本地系列备件与调拨成本；
- 调机航班与远程运营附加费。

收益预测必须把基地成本按其服务的航线、舰船和转机旅客合理分摊，同时保留基地整体损益，避免把所有基地开销隐藏在公司总账。

## 本版本不包含

- AI 完整自主基地投资；静态 AI 使用预生成合法基地网络；
- 地产、城市建设和星港所有权；
- 逐名员工招聘与排班；
- 航司联盟共享基地资产。

## 验收标准

1. 玩家至少能同时运营总部和一个区域/前进基地；
2. 航线可从不同基地始发，舰船位置和轮转全程连续；
3. 基地容量不足会阻止新增驻扎、维护或始发任务；
4. 调拨舰船消耗真实时间、燃料和时隙，不允许瞬移；
5. 远离支持基地会增加可解释的成本与运营风险；
6. 关闭基地不会遗留无归属舰船、维护订单或非法航线；
7. 基地损益、航线分摊与公司总账严格对平；
8. 多基地网络能明显改变转机覆盖和航线策略，而不是只有新的起点按钮。
